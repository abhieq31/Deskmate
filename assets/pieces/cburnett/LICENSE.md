# cburnett piece set

Chess piece images by [Colin M.L. Burnett](https://en.wikipedia.org/wiki/User:Cburnett),
as distributed by [lichess.org](https://github.com/lichess-org/lila/tree/master/public/piece/cburnett).

License: [GPLv2 or later](https://www.gnu.org/licenses/gpl-2.0.txt).

These files are separate assets, loaded by the app at runtime, and are not
covered by the MIT license of the Deskmate source code. To ship Deskmate under
MIT terms only, swap this folder for a piece set with a permissive license and
update the `.wK`…`.bP` rules in `css/style.css`.
